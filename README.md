# The Steward's Responsibilities

A browser-based goals and milestones tracker. Open `index.html` in a browser to use it.

## Files

- `index.html` defines the page structure, goal controls, quick notes, and General Editor.
- `styles.css` styles the page, goal controls, editors, and responsive layout.
- `script.js` initializes the app and implements goal and milestone editing, progress tracking, import/export, and quick notes.

## Quick notes

The Quick Notes panel appears immediately before General Editor. Write a note and select **Save Notes** to store it in the current browser's local storage. Saved text remains in the text box and is restored when the page is reopened in the same browser profile. **Export to .txt** also includes the current notes, and importing an exported file restores them to the text box and browser storage.
